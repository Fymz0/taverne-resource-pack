# Neuf catégories d’émojis dans le tchat

3953 émojis Emoji 17/Twemoji 17.0.3, variantes comprises, auxquels s’ajoutent les 150 icônes Iconic existantes : **4103 entrées**. Catégories : Smileys, Les gens, Animaux et nature, Nourriture et boissons, Activité, Voyages et lieux, Objets, Symboles, Drapeaux. Accès Toutes et Icônes du Comptoir conservés en plus.

Client Fabric 26.2 : bouton ☺ à gauche du check NCR, panneau défilant strictement à droite de la largeur des messages, choix de catégorie et recherche française sans accents. Le texte du message reste indépendant de la recherche ; Entrée dans la recherche revient au message et ne l’envoie pas.

**Installation client :** fermer Minecraft, remplacer uniquement Emoji Picker 1.1.0 par `lecomptoir-emoji-picker-1.2.0+mc26.2.jar`, jamais laisser deux versions ensemble, puis relancer le jeu. Le pack contient les ressources pour les destinataires sans mod ; pour avoir le bouton, le mod reste nécessaire. Publication du fichier ne signifie pas activation sur le serveur.

Les 2553 séquences composées (drapeaux, familles, couleurs de peau, etc.) disposent chacune d’un glyphe privé stable dans le pack afin de s’afficher d’un seul tenant dans Minecraft. Les 1400 autres emploient leur codepoint de base ; les 150 anciennes icônes gardent leurs codes.

16 atlas bitmap ; images officielles Twemoji redimensionnées de 72×72 à 32×32. Attribution/licences CC BY 4.0, MIT et Unicode V3 incluses. Noms/tags français : emojibase-data 17.0.0. Référence catégories : [Emojipedia](https://emojipedia.org/). Les descriptions d’Emojipedia ne sont pas recopiées.

**Contrôles :** 8224 contrôles ressources/CRC/JSON/tuiles ; 4794 contrôles natifs Fabric/NCR : polices, parcours de toutes les entrées et catégories, recherche, vrai EditBox, saisie sans effacement, foyer de recherche et Entrée sans envoi. Les composants sans fenêtre de la sonde ne sont pas inclus dans le JAR. Rendu à l’écran et clics réels encore à vérifier après lancement.

Empreintes et tailles exactes dans build.json. Le pack v15 conserve les anciens fichiers v14 sauf la description et une référence ajoutée à la police par défaut. Les sources de reconstruction et le suivi d’installation sont conservés dans le dépôt privé d’administration.
